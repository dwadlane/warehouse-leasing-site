# Warehouse Leasing Site

A one-page listing for a 17,073 square metre logistics hub for lease in Pasig City, Metro Manila. Built to get serious tenant inquiries, not just page views.

## What It Does

- Leads with the numbers a tenant checks first: size, location, access.
- Photo gallery and a short inquiry form.
- Form entries go straight to a Google Sheet and an email alert through Google Apps Script ([apps-script.js](apps-script.js)), so no inquiry sits unread.

## Built With

HTML and CSS, Google Apps Script, Cloudflare Pages.
